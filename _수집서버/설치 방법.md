# 응답을 구글 시트로 모으기 — 설치 방법

한 번만 해 두면, 누가 어디서 답하든 선생님 구글 시트에 한 줄씩 쌓입니다.
전부 무료이고 계정은 선생님 구글 계정 하나면 됩니다. **10분쯤 걸립니다.**

---

## 왜 필요한가요

지금까지는 응답이 **답한 사람의 브라우저 안에만** 남았습니다.
학생이나 동료 선생님이 GitHub 주소로 들어가 답해도 그건 그 사람 컴퓨터에 있고,
선생님 화면에는 오지 않습니다. 브라우저를 정리하거나 다른 컴퓨터로 옮기면 사라집니다.

아래 설치를 마치면 이렇게 바뀝니다.

| | 지금 | 설치 뒤 |
|---|---|---|
| 답한 것이 가는 곳 | 그 사람 브라우저 | **선생님 구글 시트** |
| 다른 사람 응답 보기 | 못 봄 | 앱을 열면 자동으로 받아옴 |
| 브라우저를 지우면 | 사라짐 | 시트에 남아 있음 |
| 인터넷이 끊기면 | — | 대기열에 뒀다가 나중에 다시 보냄 |

---

## 1. 구글 시트를 하나 만듭니다

1. <https://sheets.new> 로 들어갑니다
2. 이름을 알아보기 쉽게 바꿉니다 — 예) `기출검색기 응답`

시트 안에 탭을 미리 만들 필요는 없습니다. 스크립트가 알아서 만듭니다.

## 2. Apps Script를 붙입니다

1. 그 시트에서 위쪽 메뉴 **확장 프로그램 → Apps Script**
2. 새 탭이 열리면 안에 있던 `function myFunction() {}` 을 **전부 지웁니다**
3. 이 폴더의 **`Code.gs`** 를 메모장으로 열어 **전체를 복사**해 붙여 넣습니다
4. 위쪽 💾(저장)를 누릅니다

## 3. 웹앱으로 배포합니다

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 이렇게 맞춥니다

   | 항목 | 고를 것 |
   |---|---|
   | 설명 | 아무거나 (예: 기출검색기 수집) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > «모든 사용자»로 해야 학생이 구글 로그인 없이 답할 수 있습니다.
   > 이 주소로는 응답을 **보내고 받는 것만** 되고, 시트를 열거나 고칠 수는 없습니다.

4. **배포**를 누릅니다
5. 처음이면 권한을 묻습니다 → **액세스 승인** → 계정 선택 →
   «이 앱은 확인되지 않았습니다» 화면이 나오면 **고급 → (안전하지 않음) 이동** →
   **허용**
   *선생님이 직접 만든 스크립트라 나오는 경고입니다*
6. 마지막에 뜨는 **웹 앱 URL**을 복사합니다.
   `https://script.google.com/macros/s/AKfycb....../exec` 처럼 생겼습니다

## 4. 앱에 주소를 넣습니다

1. `index.html` 을 **메모장**으로 엽니다
2. 위쪽에서 이 줄을 찾습니다 (`Ctrl+F` 로 `COLLECT_URL` 검색)

   ```
   var COLLECT_URL = '';
   ```

3. 따옴표 **안에** 3번에서 복사한 주소를 붙여 넣습니다

   ```
   var COLLECT_URL = 'https://script.google.com/macros/s/AKfycb....../exec';
   ```

4. 저장하고, GitHub에 올리시는 파일도 이 파일로 바꿔 주세요

## 5. 되는지 확인합니다

1. 앱을 열고 첫 화면의 의무 응답 3건을 답합니다
2. 제목을 세 번 클릭 → 비밀번호 → **수집 상태** 탭
3. **«보낸 응답 3건 · 못 보낸 응답 0건»** 이면 성공입니다
4. 구글 시트로 가 보면 `비교` `성취기준` 탭이 생기고 줄이 쌓여 있습니다

---

## 알아두실 점

**앞으로 파일을 새로 드려도 응답은 안전합니다.** 응답은 시트에 있으니
`index.html` 을 몇 번을 바꾸셔도 그대로입니다. 다만 새 파일에는
`COLLECT_URL` 이 다시 비어 있으니 **주소를 다시 넣어 주셔야** 합니다.
(제게 주소를 알려 주시면 넣어서 드리겠습니다.)

**인터넷이 끊겨도 잃지 않습니다.** 못 보낸 응답은 브라우저에 대기열로 남아 있다가
다음에 앱을 열 때 자동으로 다시 갑니다. 관리자 → 수집 상태에서 «지금 보내기»로
직접 보낼 수도 있습니다.

**같은 응답이 두 번 가도 괜찮습니다.** 응답마다 고유 번호가 붙어 있어 시트에서 걸러 냅니다.

**이름은 여전히 묻지 않습니다.** 시트에 남는 것은 `u3k9xz` 같은 익명 번호뿐입니다.

**스크립트를 고치셨다면** 반드시 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**
를 해야 반영됩니다. 저장만으로는 바뀌지 않습니다. **주소는 그대로 유지됩니다.**

## 시트에 생기는 탭

| 탭 | 담기는 것 |
|---|---|
| `비교` | 유사문항 비교 응답 |
| `성취기준` | 문항별 성취기준 |
| `유사아님` | «유사하지 않아요» 제보 |
| `오류제보` | 잘못 잘린 문항 제보 (파일 이름·유형·메모·처리 여부) |
| `교과목` | 문항별 교과목 (중학교·고1·대수·미적분Ⅰ·Ⅱ·기하·확률과 통계) |
| `지운응답` | 관리자가 지운 기록 (되살아나지 않게 하는 표시) |
| `사용기록` | 방문·검색·인쇄·복사 기록 (관리자 모드 «방문 통계»의 재료) |

탭은 첫 응답이 들어올 때 자동으로 만들어집니다. 미리 만드실 필요 없습니다.

**잘못 잘린 문항을 고치실 때는** `오류제보` 탭을 CSV로 받아 주시면 됩니다.
`파일` 칸(`suneung/040_06.png`)만 있으면 원본 PDF에서 다시 잘라 낼 수 있습니다.
이미 고친 것은 `처리` 칸에 «처리완료»로 표시되니 겹치지 않습니다.

## 잘 안 될 때

| 증상 | 이유와 해결 |
|---|---|
| 수집 상태에 «못 보낸 응답»만 쌓임 | 주소 끝이 `/exec` 인지 확인하세요. `/dev` 는 본인만 됩니다 |
| «액세스 권한» 오류 | 배포할 때 «모든 사용자»가 아니라 «나만»으로 되어 있습니다. 다시 배포하세요 |
| 시트에 아무것도 안 쌓임 | Apps Script 화면 왼쪽 «실행» 기록에서 오류를 볼 수 있습니다 |
| 시트가 너무 커짐 | 오래된 줄을 다른 시트로 옮겨 두셔도 됩니다. 앱은 최근 것부터 받아 갑니다 |
| 통계가 «불러오지 못했습니다» | 스크립트를 고친 뒤 다시 배포하지 않으셨습니다. 아래를 보세요 |

---

## 스크립트를 고친 뒤에는 반드시 다시 배포

Apps Script는 **저장만 해서는 웹에 반영되지 않습니다.**

```
Apps Script 화면 → 오른쪽 위 «배포» → «배포 관리»
→ 연필 모양(수정) → 버전을 «새 버전» 으로 → «배포»
```

주소(`/exec`)는 그대로이니 앱은 고치실 필요가 없습니다.
지금 기다리고 있는 것이 둘 있습니다 — **`교과목` 시트**와 **`사용기록` 시트**입니다.

---

## 사용기록에 무엇이 담기나

| 칸 | 담기는 것 |
|---|---|
| `종류` | 방문 · 검색 · 인쇄 · 복사 · 담기 · 유사 |
| `값` | 검색어, 문항 이름(«26학년도 수능 공통 10번»), 내보내기 방식 |
| `수` | 검색 결과 문항 수, 내보낸 문항 수 |
| `기기` | 화면 너비로 가른 «PC / 모바일» |
| `익명번호` | 브라우저가 만든 무작위 번호 (`u3k9f2a` 꼴) |

**이름·주소·IP는 담기지 않습니다.** 구글 앱스스크립트는 접속자 IP를 알려 주지 않고,
앱도 보내지 않습니다. 익명번호로는 «같은 브라우저인가»만 알 수 있어
다시 온 사람인지 세는 데에만 씁니다.

통계는 `?what=stat` 으로 물어보면 스크립트가 **다 세어서 요약만** 돌려줍니다.
기록이 수만 줄이 되어도 오가는 자료는 작게 유지됩니다.

기록을 아예 남기고 싶지 않으시면 `index.html` 에서
`var STAT_ON = true;` 를 `false` 로 바꾸시면 됩니다.
