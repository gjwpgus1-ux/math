# 새 시험을 앱에 넣는 순서

선생님이 하실 일은 **PDF를 폴더에 넣고 말씀하시는 것**뿐입니다.

```
1. 데이터베이스\새로들어온것\  에 PDF를 넣는다
2. 「새 시험 넣어 줘」라고 말한다
3. (제가 작업 — 아래 참고)
4. GitKraken에서 Push
```

## 제가 하는 일

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 1 | PDF에서 글자와 문항 위치를 읽는다 | 1~3분 |
| 2 | 단 경계를 보정하고 문항을 확정한다 | 1분 |
| 3 | 문항마다 그림을 잘라 `img` 에 넣는다 | 2~5분 |
| 4 | 검색 색인·유사문항 후보·클릭복사 자료를 다시 만든다 | 3~5분 |
| 5 | 문항 수와 번호가 빠짐없이 들어갔는지 검사한다 | 1분 |
| 6 | 커밋한다 | — |

시험 하나(30문항 안팎)면 **10분 안쪽**입니다.

## 확인해 주셔야 할 것

**시험 이름을 제가 못 읽는 경우가 있습니다.** 문제지 머리글이 그림으로 되어 있거나
표기가 낯설면 여쭤보겠습니다. 이때 알려 주실 것은 네 가지입니다.

- 연도 (2026년 / 27학년도)
- 시행 (3월 · 6월 · 수능 …)
- 대상 (고1 · 고2 · 고3 · 수능모평)
- 과목 (공통 · 확률과 통계 · 미적분 · 기하)

**한 PDF에 여러 과목이 있으면** 그대로 두셔도 됩니다. 과목별로 나눠 넣습니다.

**스캔본(글자가 없는 그림 PDF)도 됩니다.** 다만 검색 글자를 만들 수 없어
연도·시행·번호로만 찾게 됩니다. 그런 경우 미리 알려 드리겠습니다.

## 다 되면

- 새 문항이 검색에 나옵니다
- 유사문항 추천 후보에도 들어갑니다
- 그 PDF는 `데이터베이스\입력완료\` 로 옮겨 둡니다

## 새 시험을 넣었다면 한 단계 더

문항에는 «수식이 살아 있는 글»이 따로 붙어 있습니다.
(`x^2`, `a_n`, `√`, `Σ`, `∫`, `π` 로 찾을 수 있게 하는 글입니다.)

새 수능·모평을 넣은 뒤에는 이것도 다시 만들어야 그 시험이 수식으로 찾힙니다.

```
python3 build_formula.py <questions.json> <pdf> f.json
python3 add_formula_to_index.py ../data/index.js f.json
```

지금 5,560문항(전체의 95.9%)에 붙어 있습니다.
안 붙은 240문항은 글자가 없는 스캔본 8개 시험이라 만들 수 없습니다.
그 문항은 예전 방식으로 찾힙니다.

## 해설을 함께 넣었다면 한 단계 더

해설 PDF를 `해설파일(정리 전)\전국연합_고N\해설\` 에 `2609_고1_해설.pdf` 꼴로
넣고 아래를 차례로 돌립니다.

```
python3 build_sol.py       # 문항별 해설 그림 → img/해설, data/sol.js
python3 build_intent.py    # 해설의 «[출제의도] …» → 출제의도.json
python3 build_course.py    # 문항별 과목 → data/course.js
python3 build_sim.py ..    # 유사문항 다시 계산
```

`build_course.py` 는 과목·단원 필터를 만드는 것이라, 새 시험을 넣을 때마다
함께 돌려야 그 시험이 걸립니다. 과목은 아홉 갈래입니다.

> 중학교수학 · 공통수학1 · 공통수학2 · 대수 · 미적분Ⅰ · 미적분Ⅱ · 확통 · 기하 · 교육과정 밖

과목 아래 단원은 `단원표.py` 에 있습니다. 단원을 손볼 일이 있으면 그 파일만
고치면 됩니다 — 차례가 곧 규칙이라, 좁은 말을 위에 두어야 합니다.

`--dry` 를 붙이면 저장하지 않고 몇 개가 가려졌는지만 보여 줍니다.
낱말로 못 가린 것은 `과목_손입력.json` 에 «그림경로: [과목, 단원]» 으로
적어 두면 됩니다. 이 표는 자동 분류보다 세서, 잘못 가려진 것을 바로잡는
데도 씁니다. 지금 100문항이 들어 있습니다.

## 손으로 고치는 길

앱에서 관리자로 들어가 **과목·단원** 탭을 열면

- 과목마다 몇 문항인지, 단원을 못 가린 것이 몇 개인지 보입니다
- 못 가린 문항이 줄줄이 나오고, 「단원 고르기」로 바로 고칠 수 있습니다
- 문항 카드 머리의 «과목 · 단원» 단추로도 아무 문항이나 고칠 수 있습니다
- 다 고쳤으면 「고친 것 JSON으로 저장」을 눌러 받은 파일을
  `과목_손입력.json` 에 합치고 `build_course.py` 를 다시 돌리면 됩니다

지금 단원을 못 가린 문항은 166개이고, 목록은 `단원_못가린문항.csv` 에 있습니다.
