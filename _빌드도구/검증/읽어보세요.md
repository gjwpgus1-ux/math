# 자동 점검 스크립트

앱을 가상 브라우저(jsdom)에 띄워 기능이 살아 있는지 확인합니다.
파일을 고친 뒤 돌려 보면 어디가 깨졌는지 바로 나옵니다.

```
npm install jsdom
node regress.js     # 전체 기능 훑기
node tip.js         # 오답노트 팁 팝업
```

`harness.js` 는 두 파일이 함께 쓰는 준비 코드입니다.
앱 폴더 경로가 바뀌면 `harness.js` 위쪽의 `APP` 만 고치시면 됩니다.

## 묶음 목록

| 파일 | 보는 것 |
|---|---|
| regress | 검색·필터·목록 전반 |
| filter | 필터 값과 차례 |
| print | 학습지·오답노트 짜임새 |
| ui | 화면 요소와 문구 |
| gate·gate2·gate3 | 시작 팝업 질문 |
| sync | 구글시트 주고받기 |
| copy | 클릭 복사 |
| year | 학년도와 실시 연도 |
| tip | 오답노트 팁 팝업 |
| course | 교과목 질문 |
| pdf | PDF 내려받기 |
| **formula** | **수식 검색 — 바꿔쓰기·대소문자·색인** |
| **comma** | **쉼표로 여러 조건 묶어 찾기** |
| **help** | **검색 도움말 팝업 · Ctrl+화살표 탭 이동** |
| **stat** | **방문 통계 — 기록 쌓기·그래프·개인정보** |
| **pages** | **소개·개인정보·문의 세 쪽과 꼬리말** |
| **keys** | **단축키 (/ · 1~4 · f · ? · k)와 단축키 창** |
| **tabs** | **탭 폭 고정 · 닫기 · 모두 닫으면 처음으로** |
| **brand** | **사이트 이름(줍줍닷컴)·부제·모드 단추** |

전부 돌리려면:

```
for f in regress filter print ui gate gate2 gate3 sync copy year tip course pdf formula comma help stat pages keys tabs brand; do node $f.js; done
```
