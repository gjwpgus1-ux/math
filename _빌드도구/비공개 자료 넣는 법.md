# 잠가서 올리는 자료

밖에 알려지면 안 되는 문항을 **암호로 잠가서** 올립니다.
암호를 오프라인으로 받은 사람만 볼 수 있고, 나머지 사람에게는 **그런 문항이 있다는 것조차** 보이지 않습니다.

## 어떻게 여나

검색창에 **암호를 그대로 치고 Enter**. 그것이 전부입니다.

- 단추도, 메뉴도 없습니다. 암호를 모르면 찾을 것이 없습니다.
- 틀리면 여느 「결과 없음」과 똑같습니다. 아무 표시도 나지 않습니다.
- 열리면 검색창이 비워지고, 그 문항들이 여느 문항처럼 검색됩니다.
- **새로고침하면 다시 잠깁니다.** 어디에도 남기지 않습니다.

## 넣는 순서

```
1) 시험지 PDF 를 공개본과 똑같이 크롭한다  (extract → assemble → render)
   작업 폴더는 반드시 저장소 밖에 둔다.  예) D:\비공개작업\
2) python build_secret.py D:\비공개작업 작업이름
3) 암호를 두 번 넣는다
4) data/aux.bin 하나만 올라간다 (Push)
```

넣을 때마다 **전체를 다시 만듭니다.** 이미 넣은 것에 더하려면 작업 이름을 모두 적으세요.

```
python build_secret.py D:\비공개작업 1차 2차 3차
```

## 꼭 지킬 것

- **암호는 어디에도 저장하지 않습니다.** 잊으면 되살릴 방법이 없습니다.
- **원본 PDF 와 작업 폴더는 저장소 안에 두지 마세요.** `_비공개/`, `_비공개원본/` 은
  올라가지 않도록 막아 두었지만, 아예 다른 드라이브에 두는 편이 안전합니다.
- 암호는 **8자 이상**, 되도록 길게. 짧으면 찍어 맞힐 수 있습니다.

## 무엇까지 감춰지나

**감춰지는 것**

- 문항 그림, 시험 이름, 문항 수, 검색용 글 — 전부. `aux.bin` 은 암호 없이는 뜻 없는 바이트입니다.
- 열린 뒤에도 이 문항들의 이름은 **구글 시트로 나가지 않습니다.**
  사용기록·오류제보·유사문항 응답 모두 막아 두었습니다.
- 아무것도 못 찾은 8자 이상 검색어는 시트에 글자 그대로 남기지 않고
  「긴 검색어 · 결과 없음」으로만 셉니다. 암호를 잘못 쳐도 시트에 남지 않습니다.

**감출 수 없는 것**

- 저장소가 공개(Public)라 `data/aux.bin` 이라는 **파일이 있다는 사실**은 보입니다.
- `index.html` 을 읽는 사람은 **잠긴 자료를 푸는 코드가 있다**는 것을 알 수 있습니다.
- 즉 「무언가 감춰 두었다」까지는 알 수 있고, 「그것이 무엇인지」는 알 수 없습니다.

이것까지 감추려면 아예 다른 비공개 사이트로 나누는 수밖에 없습니다.

## 자물쇠

| | |
|---|---|
| 열쇠 만들기 | PBKDF2-HMAC-SHA256 · 소금 16바이트 · 250,000번 |
| 자물쇠 | AES-256-GCM · nonce 12바이트 |
| 파일 짜임 | `JJ1` + 소금(16) + nonce(12) + 잠긴 내용 |

브라우저에 원래 들어 있는 기능만 씁니다. 따로 받아 오는 라이브러리가 없습니다.
암호가 맞는지는 **풀어 보고 판단**합니다. 암호나 그 지문을 어디에도 두지 않으므로
코드를 아무리 읽어도 암호를 캐낼 수 없습니다.

## 확인

```
cd _빌드도구\검증
node aux.js
```

맞추는 자료로 잠갔다 푸는 것까지 22가지를 확인합니다.
