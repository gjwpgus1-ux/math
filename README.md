# 수학 수능/모평/학평 기출문제 검색기

문구·연도·시행·과목·문항번호로 기출문제를 찾아 **이미지 그대로** 보여 주는 웹앱입니다.
설치가 필요 없고 `index.html` 하나만 열면 됩니다.

- 시험 286개 · 문항 5,694개 (2016~2026년 시행 · 수능·모의평가 / 고1·2·3 전국연합)
- 문항검색 모드 · 학습 모드 (학습지·오답노트 인쇄)
- 비슷한 문항 추천, 2022 개정 교육과정 성취기준 태깅

제작 : 허선생

## 쓰는 법

`index.html` 을 브라우저로 엽니다. 자세한 설명은 [사용설명.md](사용설명.md)를 보세요.

## 폴더

```
index.html      앱 본체 (이 파일 하나가 전부입니다)
data/           검색 색인 · 유사문항 후보 · 성취기준
img/            문항 이미지 5,694장
_수집서버/       응답을 구글 시트로 모으는 스크립트
_빌드도구/       PDF에서 문항을 잘라내는 제작 스크립트
```

## 저작권

문항의 저작권은 **한국교육과정평가원**과 **시·도교육청**에 있습니다.
이 저장소는 교육 목적의 검색 도구이며, 문항 자체를 배포할 권리를 주장하지 않습니다.
공개 여부를 정하실 때 이 점을 함께 살펴 주세요.
